## Install in 3 Steps

### For New Installations

```bash
# 1. Run installer
bash proxmox-create-and-install-spotweb.sh

# 2. When prompted, select:
Select theme option [1]: 3

# 3. Done! Open Spotweb and switch themes!
```

### For Existing Installations

```bash
# 1. Enter container
pct enter <container-id>

# 2. Run theme installer
sudo bash install-theme-pack.sh

# 3. Reload browser - done!
```

---

## Use Themes

1. **Open Spotweb**
2. **Click theme dropdown** (top-left toolbar)
3. **Select your favorite** ✨

**Your choice is saved automatically!**

---

## Create Custom Theme

1. **Open** `tools/theme-customizer.html` in browser
2. **Pick a preset** to start from
3. **Adjust colors** with pickers
4. **Download CSS** when happy
5. **Done!**
